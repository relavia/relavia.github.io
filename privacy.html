隐私说明

这一页写清 Relavia 会碰什么数据、不会碰什么。每一条都可以拿公开的代码核对。

无账号、无日志、无遥测

客户端不需要注册，不收集、不上报任何使用数据：没有统计 SDK，没有崩溃上报通道，没有广告标识符。项目也不运营任何服务器来接收这类数据。

没有中心服务器

项目不运营中转或控制服务器。你的流量只在你的设备与你选择的节点之间流动；某个节点会如何记录，取决于该节点的运营者，不经过我们。

你的数据只存在本机

节点、订阅与设置都保存在你本机，并可设置口令加密（口令经 Argon2id 派生密钥，数据以 XChaCha20-Poly1305 加密）；导出备份强制加密，不存在明文备份。我们没有任何云端副本，删掉本机数据即彻底清除。

更新检查会发出什么请求（如实说明）

更新检查只做一件事：从 GitHub Releases 拉取一份静态清单文件。它不上传任何设备信息：请求头只有 User-Agent: Relavia/<版本号>，不带设备、系统、地区或语言标识，也没有 Cookie。定期检查默认关闭；只有你手动点「检查更新」，或主动开启定期检查后（至多每 24 小时一次、在启动时），才会发出请求。清单所在的服务器会看到你的 IP 地址——这是下载任何静态文件的固有事实，我们如实写明，不做虚假承诺。并且无论哪种方式，都只检查、只提示，永不自动下载或安装，下载与安装每一步都要你确认。

关于本站

本站是纯静态页面：没有统计脚本，没有 Cookie，不加载任何第三方资源。你的浏览器只会从 GitHub Pages 取回这些页面文件。
