项目状态

Relavia 目前处于积极开发阶段，v1.0 尚未发布。本站不提供任何安装包下载：源码在 GitHub 仓库中公开，未来的正式版本将只通过仓库的 Releases 页发布。任何声称提供 Relavia 安装包的其他网站均非官方渠道。

设计原则

无账号

不需要注册，不绑定任何身份。下载、安装、使用，全程没有账户体系。

无日志、无遥测

客户端不收集、不上报任何使用数据。没有统计 SDK，没有崩溃上报通道。你可以用代码验证这一点。

无中心服务器

项目不运营任何中转或控制服务器。你的流量只在你的设备与你自己的节点之间流动。

自备节点

Relavia 是客户端，不是服务商：不卖节点、不运营节点。你配置自己的服务器，或使用经授权的公开来源。

GPL 开源

代码以 GPL-3.0-or-later 发布，任何人都可以审计、修改与再分发。这是信任的基础，不是营销话术。

协议支持

以下为第一梯队目标协议，正在开发与逐项验证中；某个协议在某个版本中是否可用，以该版本的发布说明为准。

  • Shadowsocks
  • Trojan
  • VMess
  • VLESS + Reality
  • Hysteria2
  • TUIC
  • WireGuard
  • OpenVPN
  • SOCKS5 / HTTP

OpenVPN 按许可证审计结论以独立进程形式集成；第二梯队协议（SoftEther / L2TP / SSTP）走编排集成，不进入内核。

来源政策

Relavia 只接入获得授权的节点来源，绝不抓取来路不明的免费节点列表——那些节点大多是被泄露或被入侵的他人设备。来源以插件形式接入，每个来源都要声明其授权依据与数据政策。

一期唯一公共源：VPN Gate

VPN Gate（筑波大学学术项目）是一期唯一的公共节点来源。请注意其官方政策：连接日志保留 3 个月以上，中继侧数据包日志保留 2 周以上，并可能应警方或法院要求披露。因此它在 Relavia 中的定位是「可达性工具」，不是隐私工具；客户端在启用该来源前会强制展示完整的风险告知。
