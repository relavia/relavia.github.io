常见问题

为什么没有内置节点？

因为 Relavia 是客户端，不是服务商。内置节点就意味着有人在运营服务器、为它付费，并掌握经过的流量——那正是本项目拒绝的模式。节点请自备，或使用经授权的公开来源。

节点从哪里来？

三个正道：自己搭一台服务器；用你已有服务商给你的订阅或分享链接导入；或启用内置的 VPN Gate 公共源（务必先读风险说明页）。网上流传的「免费节点大全」大多是被泄露或被入侵的他人设备，本项目不会接入，也建议你不要使用。

Windows 打开安装包时为什么有警告？

因为我们的 Windows 程序没有商业代码签名（原因见下载页）。只要你是从 GitHub Releases 下载的、并按验签教程核对过哈希与签名，这个警告可以手动确认放行；从别处下载的包请直接删除。

怎么确认下载的包是真的？

按验签教程走：先比对 SHA-256，再用 releasetool 验更新清单的 Ed25519 签名，最后把公钥指纹与下载页公布的逐字核对。三步都不需要你信任我们的话，只需要你信任你自己算出的结果。

VPN Gate 安全吗？

它解决的是「能不能连上」，不是「隐不隐秘」。它的连接日志保留三个月以上并可依法披露，节点运行在志愿者的个人电脑上。用它做一般浏览可以，传输账号口令、财务信息等敏感内容不行。详情见风险说明页。

项目怎么维持？会收费吗？

非盈利，而且刻意做到近乎零成本：代码托管、网站、安装包分发与自动构建都使用 GitHub 对公开仓库的免费能力，项目不运营服务器、没有服务器开支。没有会员、没有卖节点、不接受「捐赠换服务」，也没有收费计划。

出了问题去哪儿反馈？

到 GitHub 仓库的 Issues 区。报问题时请带上版本号、你的系统与复现步骤；安全漏洞不要公开提交，请按仓库 SECURITY.md 的说明走私密报告渠道。公开 Beta 期间将开通带模板的反馈通道，并由维护者分诊、回复与跟进修复——该闭环随 Beta 一并上线，本页先行说明。

支持哪些系统？

首发平台是 Windows 与 Android，两者都在开发与 Beta 准备中；macOS 在后续阶段规划内。各协议与平台模式的实际支持状态以兼容矩阵页为准——那里写的是实测状态，不是愿望清单。
